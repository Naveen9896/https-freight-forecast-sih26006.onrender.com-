PROJECT INFO

About SIH26006

🎯

Problem Statement

Ministry of Steel requires accurate bulk freight rate forecasting to optimize vessel procurement decisions for steel raw materials across Indian ports.

🤖

ML Approach

Dual-model architecture: Ridge Regression with polynomial interaction features for interpretability, and XGBoost with GridSearchCV tuning for accuracy.

📦

Key Features

Route encoding, cargo volume utilisation, bunker fuel cost, cyclical seasonal demand, port congestion index, and vessel class interaction features.

⚓

Procurement Output

Recommends vessel class (Handysize/Supramax/Panamax/Capesize), number of vessels, total freight cost in USD & INR, and spot vs. charter decision.
